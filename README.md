- JWT authentication

**Tech Stack:** React.js, Spring Boot, FastAPI, Python, Java, MySQL, Apify, XGBoost, ArcFace, SentenceTransformer, OpenCLIP, JWT

### 🔐 CipherForge

**Unified Data Sanitization Suite**

Cross-platform secure data wiping system focused on secure deletion, sensitive-data detection, and verifiable audit reporting.

**Highlights**

- Secure file and data wiping
- Multi-standard deletion
- AI-assisted sensitive-data detection
- Tamper-proof audit certificates
- Android reset through ADB
- OCR-based sensitive-data detection
- QR-based certificate verification

**Supported Standards:** Gutmann, DoD, NIST

**Tech Stack:** Python, CustomTkinter, Cryptography, ReportLab, Segno, ADB, JSON, spaCy, Microsoft Presidio, YOLOv8, Tesseract OCR
