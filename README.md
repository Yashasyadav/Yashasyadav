## 📌 Featured Projects

### 🛡️ Cyber Sentinels
AI-powered fake profile detection system for Instagram, combining profile intelligence, multimodal analysis, and risk assessment.

**Highlights**
- Automated Instagram profile data collection
- Candidate discovery using Instagram search
- Multimodal profile analysis
- Username similarity and behavioral features
- XGBoost-based candidate classification
- Risk assessment and reporting
- JWT-based authentication

**Tech Stack:** React.js, Spring Boot, FastAPI, Python, Java, MySQL, Apify, XGBoost, ArcFace, SentenceTransformer, OpenCLIP, JWT

### 🔐 CipherForge
Unified data sanitization suite focused on secure deletion, sensitive data detection, and verifiable audit reporting.

**Highlights**
- Secure file and data wiping
- Multi-standard data deletion
- AI-assisted sensitive-data detection
- Tamper-proof audit certificates
- Android reset through ADB
- OCR-based sensitive information detection
- QR-based certificate verification

**Supported Standards:** Gutmann, DoD, NIST

**Tech Stack:** Python, CustomTkinter, Cryptography, ReportLab, Segno, ADB, JSON, spaCy, Microsoft Presidio, YOLOv8, Tesseract OCR

### 💳 Trade Reconciliation Platform
Enterprise financial reconciliation platform designed to automatically match invoices, payments, and related financial records.

**Highlights**
- Automated reconciliation
- Rule-based matching
- Exception detection and alerts
- Invoice processing
- Payment processing
- Shipment processing
- Bank statement processing
- Role-based dashboards

**Tech Stack:** Spring Boot, Angular, PostgreSQL, JWT
